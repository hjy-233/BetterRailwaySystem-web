# BetterRailwaySystem

BetterRailwaySystem is a Fabric mod for Minecraft that improves the vanilla minecart system without replacing vanilla rails or turning the game into a separate transport simulator.

Core goals:

- keep vanilla rails
- change and add selected vanilla minecart behaviors
- add some features commonly found in real railway systems

## What This Site Contains

This documentation site is organized into five sections:

- **Introduction**: a general introduction to the mod.
- **Installation**: client, server, and dependency setup.
- **Tutorials**: basic operations.
- **Advanced**: system behavior and multiplayer workflows.
- **Developer**: code structure and implementation direction.
