# First Launch Checklist

After installing the mod, verify these items before building a larger railway system.

## In the Creative Inventory

Open the redstone tab and confirm these blocks are visible:

- railway transponder
- stop rail
- train spawner
- train collector

## In the Config UI

Open the config screen and confirm you can see editable values for:

- max speed
- acceleration
- deceleration
- safe following distance
- unattended despawn time

## In the World

Create a short powered-rail test line and confirm:

- the minecart accelerates smoothly
- the minecart slows smoothly on unpowered powered rails
- no obvious startup errors appear in logs

## On a Dedicated Server

If you are testing on a server, also verify:

- the server starts with the mod installed
- both client and server have the required dependencies
- the client can open BetterRailwaySystem screens on that server
- asset sync requests do not show the “server missing” message
