# First Transponder

`railway_balise` is the core block for station-side event triggers.

## Goal

You will replace the block under the rail with one transponder and make a minecart trigger an onboard event.

## Steps

1. Place a `railway_balise`.
2. Open its configuration screen.
3. Choose a mode such as `announcement` or `arrival`.
4. Optionally set current station, next station, title, subtitle, image ID, and sound ID.
5. Ride a minecart through the trigger area.

## Expected Behavior

Depending on the mode and fields you set, the cart passengers should receive:

- optional title/subtitle text
- optional current-station and next-station information
- optional BossBar updates
- optional image and sound playback

## Notes

- media identifiers must exist on the current client, or come from a synchronized server asset library
- only the passengers of the triggered minecart receive the announcement
