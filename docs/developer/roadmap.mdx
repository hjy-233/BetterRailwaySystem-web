# Roadmap (WIP)

The project already covers the main vanilla-rail enhancement loop, but several improvements remain attractive.

## Near-Term Directions

- richer asset management, including delete and overwrite workflows
- stronger server-side permission and safety controls for media upload
- more route and map tooling
- more polished documentation and release packaging

## Longer-Term Possibilities

- deeper operational scheduling tools
- larger map visualization improvements
- better large-network performance tuning
- additional server administration controls

## Documentation Direction

This documentation site will continue to expand in parallel with the mod, especially around:

- dedicated server workflows
- multiplayer media sync
- route recording edge cases
- developer-facing implementation notes
