# BetterRailwaySystem

BetterRailwaySystem 是一个基于 Fabric 的 Minecraft 模组，用来增强原版矿车系统，而不是替换原版铁轨，也不是把游戏变成一套独立交通模拟器。

核心目标：

- 保留原版铁轨
- 更改、增加一些原版矿车行为
- 补充一些现实中铁路系统常见的功能
