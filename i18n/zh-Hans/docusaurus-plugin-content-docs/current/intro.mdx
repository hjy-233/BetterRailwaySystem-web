# BetterRailwaySystem

BetterRailwaySystem 是一个基于 Fabric 的 Minecraft `1.21.1` 模组，用来增强原版矿车系统，而不是替换原版铁轨，也不是把游戏变成一套独立交通模拟器。

这个项目围绕一个核心思路展开：

- 保留原版铁轨、动力铁轨、检测铁轨和激活铁轨
- 通过行为增强来改善矿车运行和铁路运营体验
- 在原版矿车周围补充运营方块和线路管理工具

## 你可以期待什么

BetterRailwaySystem 当前主要覆盖五个方向：

1. 更平滑、更稳定的矿车高速物理。
2. 通过 Balise、Stop Rail、Spawner、Collector 提供更实用的铁路运营能力。
3. 面向多人联机的矿车行为与专用服务器支持。
4. 世界铁路网录入与线路图展示。
5. 站点图片与语音素材的共享工作流。
