# 网络与数据

BetterRailwaySystem 通过自定义 payload 实现编辑界面、线路图以及素材同步。

## 网络分组

主要数据包分为：

- 打开方块编辑界面
- 保存方块配置
- 请求线路图
- 清除铁路网数据
- 素材上传与素材同步

## 持久化数据

服务端会保存这类线路数据：

- 城市名
- 线路编号
- 方向
- 站点列表
- 线路颜色
- 站点坐标

## 素材数据

同步素材目前采用：

- 客户端本地上传暂存目录
- 服务端素材存储目录
- 分块网络下发
- 客户端重建本地资源包并重载
