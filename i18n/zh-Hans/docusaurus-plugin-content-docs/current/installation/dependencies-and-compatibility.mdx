# 依赖与兼容性

## 运行时依赖

BetterRailwaySystem 当前需要：

- Minecraft `1.21.1`
- Fabric Loader
- Fabric API
- Cloth Config
- Java `21+`

## 与原版系统的兼容目标

本模组明确围绕原版铁路系统设计：

- 普通铁轨
- 动力铁轨
- 检测铁轨
- 激活铁轨
- 基于红石的站点逻辑

目标是在不替换原版轨道的前提下增强行为。

## 客户端与服务端兼容范围

### 完整支持

- 单机
- 双方都安装模组的局域网世界
- 配套安装的 Fabric 专用服务器

### 受限情况

如果客户端连接到未运行 BetterRailwaySystem 的服务器：

- 线路图请求会被禁用
- 服务端素材上传与同步会被禁用
- 相关界面会显示清晰提示，而不是继续尝试错误行为

这是一种有意设计的保护机制。
