# 首次启动检查

安装完成后，建议先确认下面这些项目，再开始搭复杂线路。

## 创造物品栏

打开红石分类，确认能看到这些方块：

- 铁路应答器
- 停车轨
- 发车器
- 收车器

## 配置界面

打开配置页面，确认可以看到并修改这些选项：

- 最高速度
- 加速度
- 减速度
- 安全跟车距离
- 无人矿车删除时间

## 世界内基础测试

先搭一段短的动力铁轨线路，并确认：

- 矿车会平滑加速
- 未充能动力铁轨上会平滑减速
- 日志里没有明显启动错误

## 专用服务器额外检查

如果你在测试服务端，还要确认：

- 服务端能正常加载本模组
- 客户端和服务端的依赖一致
- 方块配置界面可以在该服务器上正常打开
- 素材同步不会出现“服务器未安装模组”的提示
