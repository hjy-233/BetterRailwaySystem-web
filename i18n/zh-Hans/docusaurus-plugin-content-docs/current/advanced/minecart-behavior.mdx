# 矿车行为

BetterRailwaySystem 对矿车运动的修改，优先针对原版铁路玩法中最屎的部分。

## 平滑速度模型

动力铁轨不再是“瞬间跳到固定速度”。模组会根据配置项逐步施加加速度与减速度。

## 稳定性目标

当前实现重点改善：

- 高速弯道通过
- 坡道通过
- 高速脱轨概率
- 动量保持（类似于新版实验性功能中的矿车增强的效果）

## 跟车与阻挡

当前方同轨路径上存在另一辆矿车时，系统会尝试保持一个可配置的安全距离。如果碰撞已经难以避免，制动会变得更激进。

不保证避免任何碰撞。

## 空车清理

无人乘坐的矿车会在配置时间后自动删除，这对长时间运行的服务器尤其重要，可以避免空车长期堆积。
