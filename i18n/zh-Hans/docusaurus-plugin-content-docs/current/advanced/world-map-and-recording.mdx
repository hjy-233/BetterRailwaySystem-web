# 世界路网与线路录入

地图系统把反复运行的列车行为变成可以复用的线路数据。

## 录入依赖什么

线路录入通常依赖：

- 来自发车块的线路身份
- 来自 Balise 的站点访问记录
- 一次完整的线路完成流程，例如到达 Collector 或返回环线起点

## 会保存哪些数据

系统会记录：

- 城市名
- 线路编号
- 线路方向
- 线路颜色
- 站点顺序
- 站点坐标

## 世界路网行为

世界路网支持：

- 按城市分组
- 线路颜色图例
- 同城同名站点自动合并为换乘点
- 搜索
- 缩放与平移

## 车上线路图

乘车状态下，玩家可以直接打开当前线路的视图，而不是整个世界铁路网。这对于测试单条线路或查看当前站点顺序非常有用。
