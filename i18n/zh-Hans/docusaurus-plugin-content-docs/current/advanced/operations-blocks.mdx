# 运营方块

运营方块系统让 BetterRailwaySystem 不只是“更快的矿车”，而是一套更可用的铁路运营层。

## 铁路应答器

- 到达/离开站点广播
- 给乘客发送广播
- 设置区间限速范围
- 更新 BossBar

## 停车轨

- 进站停车
- 停留计时
- 红石放行
- 稳定的再次发车

## 发车器

- 指定城市和线路身份
- 指定发车方向
- 维持目标矿车数量
- 处理环线发车

## 收车器

- 终点收车
- 完成线路录入
- 防止线路终点长期堆积实体

这四类方块共同构成了一套建立在原版铁轨上的运营系统。
