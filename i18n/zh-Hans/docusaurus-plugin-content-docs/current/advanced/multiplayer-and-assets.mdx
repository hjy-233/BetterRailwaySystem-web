# 联机与素材

BetterRailwaySystem 是按多人环境来设计的，但部分系统必须建立在客户端和服务端都安装模组的前提下。

## 功能门控

如果客户端连接到一个没有暴露 BetterRailwaySystem 网络通道的服务器：

- 线路图请求会被阻止
- 服务端素材同步会被阻止
- 相关界面会显示明确的禁用提示，而不是继续尝试错误行为

## 共享素材库

在已安装模组的服务器上，同步素材支持：

- 服务端保存 Balise 图片
- 服务端保存 Balise 音频
- 向在线客户端分发素材库
- 新玩家进服时自动同步

## 权限模型

在专用服务器环境下，素材上传应只开放给可信玩家，例如管理员，以避免将其变成无门槛的文件上传入口。
