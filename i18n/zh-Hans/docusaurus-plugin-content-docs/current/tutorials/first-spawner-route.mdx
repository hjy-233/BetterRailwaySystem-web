# 第一个发车与线路录入

这个教程把发车与线路录入系统连起来。

## 目标

配置一个 `train_spawner`，并让一条线路能被录入到世界铁路网。

## 步骤

1. 在有效轨道下方或旁边放置 `train_spawner`。
2. 打开发车块界面。
3. 设置城市名。
4. 设置线路编号。
5. 选择线路颜色。
6. 设置方向。
7. 设置目标车数。
8. 在线路上布置一个或多个 Balise。
9. 在线路终点放置 `train_collector`，或者将其设计为环线。

## 预期结果

当矿车完成一次线路流程后：

- 经过的站点会被记录
- 线路颜色会被保存
- 这条线路之后可以出现在世界铁路网中

## 建议

尽量保持站名一致。同一城市内重复站名会在铁路网中被视为换乘站。
