# 服务端素材同步

本页说明当前的素材同步工作流。

## 前置条件

- 服务器必须安装 BetterRailwaySystem
- 客户端也必须安装 BetterRailwaySystem
- 在专用服务器上，上传玩家通常需要管理员级权限

## 步骤

1. 从 Balise 编辑界面打开素材库。
2. 点击 **打开文件夹**。
3. 将 `.png` 或 `.ogg` 文件拖入上传暂存目录。
4. 回到游戏并点击 **刷新**。
5. 客户端会把这些文件上传到服务端。
6. 服务端保存后会将当前素材库重新广播给在线玩家。
7. 客户端收到后会把同步素材写入本地资源包并重载。

## 这意味着什么

同步完成后：

- 同一个素材标识符可以被该服务器上的多个玩家共用
- 新玩家进服时也能收到服务端已有的素材库

## 当前限制

当前流程重点解决“上传与分发”。服务端素材的直接删除仍是后续增强方向。
