# 第一条线路

这个教程的目标是尽快让你跑起来一条可用的基础线路。

## 目标

- 一段短的往返线或环线
- 一辆矿车
- 至少一段动力铁轨
- 一次实际乘坐测试

## 步骤

1. 铺设一段短的原版铁轨。
2. 添加动力铁轨并用红石供能。
3. 在轨道上放置矿车。
4. 乘坐矿车并观察加速过程。
5. 再加上一段未充能动力铁轨，观察减速效果。

## 预期行为

- 加速应当是逐步的，而不是瞬间达到上限
- 在许多情况下，矿车会比原版更能保持动量
- 减速不应表现为生硬的急停
