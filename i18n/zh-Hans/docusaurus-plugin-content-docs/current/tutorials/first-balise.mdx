# 第一个 Balise

`railway_balise` 是铁路事件触发系统的核心方块。

## 目标

在轨道旁放置一个 Balise，并让矿车触发一次车上事件。

## 步骤

1. 在轨道旁放置一个 `railway_balise`。
2. 打开它的配置界面。
3. 选择一个模式，例如 `announcement` 或 `arrival`。
4. 填写本站或下一站字段。
5. 按需设置标题、副标题、图片 ID 和音频 ID。
6. 乘坐矿车通过触发区域。

## 预期结果

根据你设置的模式和字段，矿车乘客应收到：

- 标题 / 副标题文字
- 站点状态更新
- 可选的 BossBar 更新
- 可选的图片与音频播放

## 注意

- 媒体标识符必须在当前客户端存在，或来自已同步的服务端素材库
- 只有当前触发矿车上的乘客会收到事件
