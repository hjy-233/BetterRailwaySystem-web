# 设计目标

让原版的铁路系统更易用，贴近现实，同时保留原版的交互方式。

## 核心原则

### 保留原版铁路铺设方式

玩家应继续使用原版铁轨、动力铁轨、检测铁轨、激活铁轨以及红石逻辑。模组不应该强制引入另一套独立的铺轨方式，也不应该额外造出一套平行铁路生态。

### 保留原版矿车实体

BetterRailwaySystem 不添加全新的矿车实体（如完全基于现实的铁轨/列车外观），而是直接扩展原版矿车的行为。

### 强化行为与运营能力

- 加速
- 发车与回收
- 车上广播
- 停站控制
- 线路录入
- 线路图展示(WIP)

### 支持联机环境

真正有意思的铁路系统往往发生在多人环境里，所以专用服务器支持、素材同步、以及未装服务端模组时的功能禁用。

## 刻意不做的事情

- 做成完全独立的地铁模拟器
- 用自定义基础设施方块替换原版铁轨铺设方式
- 强制要求使用自定义列车实体才能使用主要功能
- 为了联机而放弃单机体验

## 这种设计带来的取舍

因为项目坚持基于原版铁轨运行，某些高级系统必须围绕原版限制来设计。这是刻意选择的结果。BetterRailwaySystem 更偏向兼容性与可维护性，而不是在 Minecraft 内部再造一个与原版脱节的独立铁路游戏。
