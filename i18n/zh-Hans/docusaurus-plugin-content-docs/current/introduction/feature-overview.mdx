# 功能总览

本页用于快速概览 BetterRailwaySystem 的主要功能分组。

## 矿车行为

- 已充能动力铁轨上的平滑加速
- 未充能动力铁轨上的平滑减速
- 可配置最高速度、加速度、减速度
- 基于子步进的高速运行稳定性优化
- 弯道和坡道上的脱轨抑制
- 同轨前车安全距离自动刹车

## 乘客与渲染行为

- 一辆矿车支持多名玩家同乘
- 所有乘客共享同一个原版矿车实体
- 每位玩家都保留清晰的本地第一/第三人称显示
- 其他同车玩家模型会被隐藏，避免重叠

## 铁路运营方块

- `railway_balise`
- `stop_rail`
- `train_spawner`
- `train_collector`

这些方块共同提供报站、停车、发车与终点回收能力。

## 线路录入与地图系统

- 站点访问可以录入到世界铁路网
- 支持城市与线路分组
- 乘车时可打开当前线路图
- 未乘车时可打开世界铁路网

## 联机与素材

- 支持专用服务器
- Balise 图片和音频可以从客户端上传到已安装模组的服务端
- 服务端素材可以分发给在线客户端
- 如果服务器未安装模组，依赖服务端网络的客户端功能会被自动禁用
